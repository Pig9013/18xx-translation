## 二、怎么用

### 2.1 查规

- 每个 md 的标题编号与英文原书一致，节标题后标了**原书印刷页码**；
- 术语表给"英文—推荐译名—已有中译实际用词—备注"四栏；冲突时以英文为准；
- 答疑文件每条都给**规则条款 + 实测/推导 + 可翻的原局或原页**。

### 2.2 安装 skill

把 `skills/18xx-translation` 复制到 agent 的 skills 目录（`~/.claude/skills/`、`~/.agents/skills/` 或 `~/.dsh/skills/`）。它自带：

- `references/中译排版PDF.md` —— 完整排版手册（管线、解析钩子、插图三锚、边界三坑、pymupdf 后处理、分部横幅/侧边色签、合订本体例）；
- `assets/build_railways_pdf.py`、`assets/clip_railways_art.py` —— 横版 1:1 样板；
- `assets/build_1880china_pdf.py`、`assets/clip_1880china_art.py` —— A4 竖版样板；
- `references/启动提示词.md` —— 直接可贴的开工提示词。

### 2.3 两步交付

1. **内容源** `<作品>_规则中文翻译.md`：逐段对照英文原规，不缩写/扩写/杜撰；术语裁决（附录 A）、原书勘误（附录 B）、核对记录（附录 C）。
2. **排版版** `<作品>_规则中文翻译（排版版）.pdf`：以 md 为唯一内容源，复刻原书开本/纸色/双栏，按对应位置嵌入原书插图；正文一字不改。
