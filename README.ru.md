# Китайский перевод книг правил 18xx · Рабочий процесс и готовые материалы

> Китайский перевод книг правил 18xx (железнодорожная экономическая настольная игра), в котором **единственным авторитетом остаётся английский оригинал правил**, а также PDF в типографской версии, которые «воспроизводят вёрстку оригинального издания и вставляют оригинальные иллюстрации на соответствующие места».

## 2. Как пользоваться

### 2.1 Поиск правил

- Номера заголовков в каждом md совпадают с английским оригиналом, после заголовка раздела указан **номер печатной страницы оригинала**;
- В глоссарии четыре столбца: «английский — рекомендуемый перевод — фактическая формулировка в существующих китайских переводах — примечания»; при расхождении решает английский вариант;
- В каждом пункте вопросов и ответов указаны **пункт правил + проверка в игре/вывод + партия или страница оригинала для сверки**.

### 2.2 Установка skill

Скопируйте `skills/18xx-translation` в каталог skills агента (`~/.claude/skills/`, `~/.agents/skills/` или `~/.dsh/skills/`). В комплект входят:

- `references/中译排版PDF.md` — полное руководство по вёрстке (конвейер, хуки разбора, три якоря иллюстраций, три ловушки на границах, постобработка pymupdf, баннеры частей/боковые цветные метки, правила оформления сброшюрованного тома);
- `assets/build_railways_pdf.py`, `assets/clip_railways_art.py` — образец альбомного формата 1:1;
- `assets/build_1880china_pdf.py`, `assets/clip_1880china_art.py` — образец книжного формата A4;
- `references/启动提示词.md` — стартовый промпт, готовый к вставке.

### 2.3 Поставка в два шага

1. **Исходник содержания** `<作品>_规则中文翻译.md`: поабзацное сопоставление с английским оригиналом правил, без сокращений/расширений/вымысла; терминологические решения (приложение A), исправления ошибок оригинала (приложение B), протокол сверки (приложение C).
2. **Типографская версия** `<作品>_规则中文翻译（排版版）.pdf`: единственный источник содержания — md; формат/цвет бумаги/две колонки оригинала воспроизводятся, оригинальные иллюстрации вставляются на соответствующие места; в основном тексте не изменено ни слова.
