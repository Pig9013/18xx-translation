## 〇、如何使用本表

1. **查术语**：先在第一部分「核心通用术语」找；没有再到第三部分「各作品专有术语」。
2. **翻译时**：一律使用「推荐译名」栏。该栏空缺或标 ⚠️ 的，说明中文译本无先例或存在冲突，需先与用户确认。
3. **查规时**：**第二部分「术语变体警示」**列出同一英文概念在不同作品/不同译本中的用词差异——这是 18XX 最容易踩坑的地方。
4. **术语陷阱**（第五部分）是必读项，列出英文原词的多义与易误译处。

### 1.1 股份与证书（Share & Certificate）

⚠️ **英文原文把这三个词分得很清楚，中文绝不能混用**：

## 二、术语变体警示（同一英文概念的不同用词）

### 2.1 ⚠️ 最重要：`President` vs `Director`

**不同作品用的英文原词不同，中文译法必须跟着变**：

| 英文原词 | 使用该词的作品 | 中文译法 | 统计依据 |
|----------|---------------|----------|----------|
| **President** | 1830、18USA、1833NE、1846 | 总裁 | president 出现 108／72／83／79 次，director 仅 0／1／0／1 次 |
| **Director** | **1853、1880** | 董事／董事长 | 1853：director 46 次、president **0** 次；1880：director 76 次、president **0** 次 |

- 1853 原文：`"Each Company is controlled by a Director who is also the largest (or equal largest) shareholder in the Company."`
- 1880 原文：`"The player with the most shares in a company is the Director of that company and decides how the company will act."`
- 对应的证书名：1853 = `Director's Certificate`（董事证书），1880 = `Director's Certificate`（董事证书）。
- **中文译本实际状况**：1830 中译＝总裁；1833NE 中译＝总裁；1880 中译＝**董事**（另一份更完整的 1880 译稿作「董事长」）；18Svea 中译＝**CEO**。
- **建议**：按作品原词翻译——原文 `president` 译「总裁」，原文 `director` 译「董事」。**不要跨作品统一**，否则与英文原文对不上。

## 五、术语陷阱（翻译时必查）

### 5.1 全系列通用陷阱

| 英文 | 陷阱 | 正确处理 |
|------|------|----------|
| **share / certificate / stock** | 三者常被混译为「股票」 | share＝权益单位；certificate＝实体卡片（可含 2 股）；stock＝share 的口语同义词 |
| **Bank Pool vs Open Market** | 1830 中译把 Bank Pool 译作「公开市场」，但原文 **Open Market 是「被弃置火车的市场」**，两者完全不同 | Bank Pool＝银行池（股票）；Open Market＝公开市场（火车）。**同名异指，必须区分** |
| **Par Value vs List Price** | 1833NE 术语表把 `List Price` 译作「面值」，与 `Par Value` 撞车 | Par Value＝票面价值；List Price＝标价（私有公司证书上印的价） |
| **rust / obsolete / discard / scrap / removed** | 五个词都近「移除」 | rust＝立即移出游戏；obsolete＝预告状态（下次跑车后移除，不占车辆上限）；discard＝主动弃置到公开市场；scrap＝拆解（仅普尔曼）；removed＝已出局 |
| **token** | 一词至少 6 义 | station token 车站标记／share price token 股价标记／resource token 资源标记／bridge token 桥梁标记／value token 价值标记／loan cube 贷款方块。**须逐一定名** |
| **N/M vs N+s（1833NE）** | 斜杠是「减法」，加号是「加法」，语义相反 | `3/5`＝访问 5 个只计 3 个；`3+3`＝3 城+3 小城全额计入。**写成「3/3」会彻底改变含义** |
| **Payout vs Dividend** | 二者都译「分红」 | Payout＝派息**总额**（决定股价升降）；Dividend＝**每股**股息 |
| **In Play（1833NE）** | 与 1846 定义不同 | 1833NE 的 In Play **排除已被接管的公司**，会直接让持证上限下移一行 |
| **Takeover vs Merger** | 都译「并购」 | 1833NE 明文 `"Takeovers are not mergers"`：接管后**目标公司整体消灭**，股东按当前股价受偿；合并则产生新实体、按固定比例换股 |
| **Vulnerable** | 泛译为「脆弱」 | 是**有定义的状态词**：无车或仅有被淘汰车 → 总裁**不得拒绝**接管。只要还有 1 列未被淘汰的车就可拒绝 |
| **Debt（1846）** | 误译为「负债」 | 是购买独立铁路时**直付银行、永不偿还**的那部分价款；公司收购独立铁路时**不计入价格上限** |
| **Issue / Redeem** | 与玩家买卖混用 | Issue＝公司从金库增发股份到市场（收**低一档**价）；Redeem＝公司从市场买回（付**高一档**价）。玩家买卖用现价 |
| **advance** | 泛译为「推进」 | 专指**阶段推进**，唯一触发方式＝购买下一阶段的首台车 |

### 5.2 1853 专有陷阱

| 英文 | 陷阱 | 正确处理 |
|------|------|----------|
| **Bond** | 误译「债券」 | 是**投标保证金**——诚信押金，兑现合同后退还。译「债券」会造成严重误解 |
| **Company Credits** | 误译「公司信贷／信用额度」 | 是「公司金库里的钱」。卷首虽言「不再用独立货币」，但正文仍沿用此词指公司资金 |
| **Train Number** | 误译「列车数量」 | 指列车卡上的**型号数字**（'3' 车 = 3）。列车数量应作 "number of trains" |
| **Promotion** | 误译「晋升」 | 是**板块升级**（黄→绿→棕→灰） |
| **Railhead** | 误译「铁路枢纽」 | 是「已连到本公司基地的轨道末端」，即可往外扩展的铺轨起点；与 junction（枢纽）严格区分 |
| **Manager** | 误译「经理」 | 是**无董事长时的托管者**，特性与董事长相反（不得分红、可赊购一列火车） |
| **score** | 一词两义 | §4.6 指**单回合公司总收入**（译「收益」）；§5.2 指**终局玩家得分**（译「得分」） |
| **Stage vs Phase** | 都译「阶段」会撞车 | Stage＝投标阶段（§2.5）；Phase＝游戏阶段（§4.10） |
| **Dealing Round** | 误认为独立概念 | ＝ Stock Round，同一件事的两种写法 |
| **Station vs City** | 两套词混用 | 地图上：圆圈＝city（城市）、环点＝town（城镇）；板块上：圆圈＝Large Station（大站）、横杠＝Small Station（小站） |
| **Base 三层嵌套** | 一律译「基地」 | 须区分 Base（基地标记）／Base Station（基地站）／Home Base（本部基地） |
| **buff vs beige** | 都译「米黄色」 | 是两种不同地色，且 beige 关联恒河谷地限制区，须分别译 |
| **un-redeemed** | 挂在不同对象上 | §2.7.3 未赎回**股份**（仍算已发行、不计股息）vs §5.2.1 未取回**保证金**。机制完全不同 |

### 5.3 1880 专有陷阱

| 英文 | 陷阱 | 正确处理 |
|------|------|----------|
| **Rust** | 文件自带中译在 p.18 表头误作**「铁路」** | 是**锈蚀／报废**（阶段变更导致超编的列车移出游戏、无补偿）。p.24 中译作「锈蚀」，须统一 |
| **Director** | 文件自带中译出现「董事长／董事／**总监**」三种 | 统一为**董事长**。「总监」为误译 |
| **Bank Pool** | 本作**没有银行池** | `"Sold shares are returned to the Bank (there is no Bank Pool)"`——卖出的股份**退回银行**，不可沿用 1830 的「银行池」 |
| **harbour / ferry / off-board** | 三概念不可混 | harbour＝港口（**计为小车站**）；ferry＝渡轮（**不是车站**，每用一次扣 ¥10）；off-board＝场外地点（**计为大车站**，且只能处于线路端点） |
| **Boomtown** | 误当普通城市 | 是**中型城市**（圈内黑点），放置时决定其为小镇还是城市板块，**升级后不可更改** |
| **Plus-Train 的两个数字** | 误译为「共 4 站」 | `2+2`：**第一个数字是线路上大车站数的上限**，第二个是车站总数上限 |
| **Restored 2-train (2R)** | 文件自带中译把 `"are available after the first 6-train is bought"` 误译，**把 2R 说成了 E 型列车** | 2R＝**修复的 2 型列车**：首辆 6 号车后可购、¥250、每公司最多 1 辆、**不锈蚀**、**不满足持车义务**、占用列车上限、购买**不推进购车标记** |
| **「do not fulfil the obligation to own a train」** | 文件自带中译作「不受拥有火车的数量限制」——**语义反转** | 正确含义：**不满足「必须拥有列车」的义务**（即不能拿它来免除强制购车） |
| **A0–A7** | 原文笔误 | 实为 **A1–A7**（组件表与 §VII 均为 A1–A7）。照抄 A0 即成错误 |
| **Priority Marker vs Train Purchase Marker** | 两者都是大木火车头，易混 | Priority Marker＝**优先权标记**（决定先手）；Train Purchase Marker（组件表作 Last Train Purchase）＝**购车标记**（标记最后购车的公司，终局决定谁最后运营） |
| **3B / B3** | 同一阶段的两种写法 | 统一为 **B3 阶段（首辆 4 号车购入）**，不要照抄「3B」 |
| **Broker's Fee vs Trading Fees** | 两个名字同一物 | 均为**交易手续费**：每卖出 10% 股份扣 ¥5，共产主义阶段照收 |
| **公司名拼写** | 德式／历史拼法 | `Schichang`＝**石长铁路**（不是「施昌」）；`Binzhou`＝**滨洲铁路**（不是山东「滨州」）；`Nanjiang`＝**南江铁路** |

### 5.4 数字陷阱

- **1830 私有公司**：第一枚新增车站 $40，其后每枚 $100；柴油车 $1100，折价换购 $800。
- **1830 票面价值**：只能是 $67 / $71 / $76 / $82 / $90 / $100（**不是任意数**）。
- **18USA 三种拍卖的最低出价各不相同**：私有公司＝面值 50%（Pyramid Scheme 例外 $5）；开办公司＝$100；公司出售＝$0（清算）／$10（收购）／市值（友好出售）。加价幅度分别是 **$5 倍数 / $1 起 / $10 倍数**。
- **1846 半额派息**：`Round this amount down to the nearest $10 and retain it in the corporate treasury`——**金库取向下取整的那部分，余数做股息**。收入 $250 → 留存 $120，每股 $13。

### 5.5 英文原规自身的含糊与错漏（引用时须留意）

18USA 规则书存在若干原文错误，翻译时**不可照字面硬译**：

1. **§9 利率设定句残缺**：`"placing the interest marker in the 'interest' column to the lef of the highest row on the from which loans have been taken."` —— `on the from which` 明显漏字。
2. **交叉引用错误**：§12 称利率设定见 §11.8，但 §11.8 是股票轮结束，实际规则在 **§9**。
3. **§14.2.2 / §14.2.3 用词错误**：两处写 `"loans acquired from the purchasing company"`，按上下文应为 **purchased** company（被收购公司）。
4. **§16 的 `set` 全书未定义**（推断＝两个营运轮及其间的并购轮）。
5. **§7.1 / §11.6.1 页码引用错误**（称 p.18、p.22，实际在 p.20、p.24）。
