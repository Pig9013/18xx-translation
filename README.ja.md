## 2. 使い方

### 2.1 ルールを引く

- 各 md の見出し番号は英語の原書と一致し、節の見出しの後ろに**原書の印刷ページ番号**を記す。
- 用語表は「英語—推奨訳語—既存の中国語訳で実際に使われた語—備考」の 4 欄。食い違う場合は英語を優先する。
- 質疑応答の各項目には**ルール条項 + 実測/導出 + 参照できる実際の対局または原書ページ**を必ず付す。

### 2.2 skill のインストール

`skills/18xx-translation` をエージェントの skills ディレクトリ（`~/.claude/skills/`、`~/.agents/skills/` または `~/.dsh/skills/`）にコピーする。同梱物は次のとおり。

- `references/中译排版PDF.md` — 組版の完全マニュアル（パイプライン、解析フック、図版の三アンカー、境界の三つの落とし穴、pymupdf による後処理、部ごとのバナー/側面の色タグ、合本の体裁）。
- `assets/build_railways_pdf.py`、`assets/clip_railways_art.py` — 横長 1:1 の見本。
- `assets/build_1880china_pdf.py`、`assets/clip_1880china_art.py` — A4 縦長の見本。
- `references/启动提示词.md` — そのまま貼り付けられる着手プロンプト。

### 2.3 2 段階納品

1. **内容源** `<作品>_规则中文翻译.md`：英語の原規と段落ごとに対照する。省略・加筆・創作はしない。用語裁定（付録 A）、原書のエラッタ（付録 B）、照合記録（付録 C）。
2. **組版版** `<作品>_规则中文翻译（排版版）.pdf`：md を唯一の内容源とし、原書の判型/紙色/2 段組を再現、原書の図版を対応する位置に埋め込む。本文は一字も変えない。
