## 模板 A：整本书中译 ＋ 原版式排版（标准两步）

`@
请翻译《<作品名>》的规则书，走 skill `18xx-translation` 的标准两步交付。

【底本】`D:\兵棋\18xx\<英文原规 PDF>`——一切以英文原规为准；已有中译只作对照，发现误译请指出并记入勘误。
【版式】<横版 285×214 / A4 竖版 / 原书实测 ___×___ mm>；纸色 <#FFF8ED / #EDE8E0 / 采样值>。

【第一步 · md】
1. 逐段对照全篇中译：不缩写、不扩写、不杜撰；标题编号与原文完全一致。
2. 先查 `18XX_中英术语对照表.md`，本作术语裁决写进附录 A；头衔按英文原词（president＝总裁 / director＝董事）。
3. 附录 B 原书勘误（位置→原文→问题→处理）；附录 C 核对记录（逐章对照了哪些页）。
4. 文首翻译人署名＋文首文末 18xx.games 致谢；文首版本沿革。
5. 交付前自检：编号连续、表格逐格、示例/注记未漏。

【第二步 · 排版版 PDF】
1. 以 md 为唯一内容源，正文一字不改；复刻原书开本/纸色/双栏/旁注盒/图注盒/宽表通栏/页脚页码。
2. 按对应位置嵌入原书插图：图 N→「图 N 说明」框；组件解剖图→组件图解各小节；公司徽记→详情卡片与旁注标题；桌面布置→对应小节。
3. 插图逐张过目 QC，边界三坑必查：邻栏正文条带 / 原书页码 / 页头装饰图标。
4. 完整性核查：标题零缺失、字符保真比 ≈1.0x、插图 N/N、目录页码回填。
5. 版本双轨（内容版＋排版版）各记沿革；快照进 `_tools/_snapshot/YYYYMMDD/`。
`@
