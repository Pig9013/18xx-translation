# 18xx 规则书中译 → 原版式排版版 PDF

> 2026-10-25 从 skill `18xx-analysis` §8 拆出，独立成 skill。原因：数据分析与规则书排版是两条互不依赖的工作线，混在一个 skill 里会让"查数据"的人读到一堆 CSS，也让排版 skill 无法单独发布。

## 0. 定位与边界

| 任务 | 用哪个 skill |
|:--|:--|
| **18xx 规则书中译 ＋ 原版式排版 PDF** | **本 skill** |
| 18xx 对局数据分析 / 复盘报告 / PPT | `18xx-analysis` |
| 兵棋规则书（SCS/TCS/GTS/OCS/VUCA/独立作品） | `wargame-translation` → `wargame-rulebook-layout`（GBII Ds 版） |
| 用户明确要求"复刻原书版式"的兵棋书 | 旧批次模板（各项目 `_tools\_legacy\`），不套 Ds 版 |

**两条铁律**：

1. **`.md` 是唯一内容源**——排版阶段不改正文一字；发现内容问题回到 md 改，再重排。
2. **英文原规是唯一权威**——已有中译只能帮助理解用词，不能覆盖原文；原书自身错误照译，另设勘误注记。

**环境**：Windows + Python 3.12 + PyMuPDF；Edge 无头是唯一高保真渲染路径（**没有** weasyprint / reportlab / pandoc / LaTeX）；控制台 GBK，跑 python 前必须 `set PYTHONIOENCODING=utf-8`。

## 2. 标准流程：两步交付（2026-10-03 起）

### 2.1 第一步：内容源 `.md`

1. **抽取原文**：双栏书用 `page.get_text('blocks')` 按块中心 x 分栏，宽 > 页宽 62% 的块（标题/通栏表/整页图）单独处理；**不要**用 `pdftotext -layout` 硬抽双栏。HTML 版规则（如 1880）按 DOM 顺序取，保留表格。
2. **术语先定**：查 `18XX_中英术语对照表.md`；本作独有术语在 md 附录 A 裁决。
   - **头衔按英文原词译**：president＝总裁（1830/1846/1880 等），director＝董事（长）（1853 等）；不跨作品统一。
   - **`Bank Pool`（股票池）与 `Open Market`（火车市场）是两个东西**；1880 没有银行池。
   - 公司缩写、车站数、票价表等**印在面板上的数字**，查面板，不凭规则书推断。
3. **逐段翻译**：不缩写、不扩写、不杜撰；标题编号与原文完全一致（3.1a/3.2f）；表格逐格；示例与设计注记照译并保持区分。
4. **原书勘误**：目录页码、笔误、交叉引用、规则与示例矛盾、编号跳跃——正文照译，另设"原书勘误注记"逐条写"位置 → 原文 → 问题 → 处理"。已知案例：1880 官方中译 Rust→"铁路"、2R→E 型车、持车义务语义反转；1817 中译是 OCR 稿、错字多。
5. **署名与致谢**：文首 `> **翻译人**：Pig9013 ｜ **使用模型**：Deepseek-flash ｜ **整理日期**：YYYY-MM-DD`；文末同义署名。
   致谢用**译文适配句式**（文首＋文末都要）：

   > `> **致谢**：术语与疑难条款参考了 **[18xx.games](https://18xx.games/)** 社区的对局与讨论；规则原文版权归原出版社所有。`

   **不要**套用分析报告的"全部对局数据来自 18xx.games……造就了这些分析"——规则书中译没有对局数据，这句话语义不成立（2026-10-25 已全量修正 7 份文档：Railways、1880、单人模式、两份答疑、术语表、规则总览）。
6. **版本沿革**：内容版 vX.Y，每次改动升版本并写清改了什么。
7. **附录**：A 专业名词对照库（本作）／B 原书勘误注记／C 核对记录（逐章对照了哪些页）。

### 2.2 第二步：原版式排版版 PDF

**复刻的不是"好看"，是原书的阅读骨架**：

| 作品 | 开本 | 纸色 | 版式 | 页数 / 体积 |
|:--|:--|:--|:--|:--|
| Railways（失落的阿特拉斯铁路 2nd） | **285×214 mm 横版** | `#FFF8ED` | 双栏杂志式；旁注盒／图注盒／公司色卡／宽表通栏 | 44 页 / 20.3 MB |
| 1880 China | **A4 595×842 pt 竖版** | `#EDE8E0` | 双栏；股份公司表带证书色块；公司徽记嵌标题 | 36 页 / 16.5 MB |

**管线**：

`@
md ──行级解析──▶ HTML+CSS（仿原书版式）
   ──Edge 无头 --print-to-pdf──▶ 原始 PDF
   ──PyMuPDF 后处理（整页纸色／页脚／页码／书签／元数据）──▶ 成品
   ──完整性核查（标题零缺失 + 字符保真比≈1.0x）──▶ 交付
`@

- Edge：`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`，参数 `--headless=new --disable-gpu --no-first-run --no-pdf-header-footer --print-to-pdf=...`；**必须经 Python subprocess 调用**（git-bash 直传中文路径有编码风险），`text=True, errors='replace'`。
- 页码/页脚 `--print-to-pdf` 不带，只能后处理盖；盖章字体用 `NotoSansSC-VF.ttf`（simhei 缺 © 字形，会渲染成 □）。
- 中文页脚用 `insert_text(fontfile=...)` 直接带字体文件，无需预注册。
- 书签 `set_toc()`（h1 一级、h2 二级）；元数据 `set_metadata()`（标题带"排版版 vX.Y"）。

**版式细则**（旁注盒、图注盒、色卡、宽表通栏、跨页表头、@page 精确到 0.5mm）见 `references/中译排版PDF.md` §3–§5——那是本 skill 的操作手册，做新作品前通读。

### 2.3 插图：按对应位置嵌入（**零遗漏**）

| 原书元素 | 嵌入位置 |
|:--|:--|
| 图 1、2… 编号插图 | md 里对应的「图 N 说明」框内（说明文字上方，含原书 Diagram 小注） |
| 组件解剖图（公司板／证书／列车卡／板块／图例） | 「组件图解」各小节标题下 |
| 小公司徽记 | 公司详情卡片标题内 ＋ 各家旁注盒标题内（矢量图 zoom 8 渲染） |
| 大公司徽记 | 「组件」条目下的徽记条 |
| 桌面布置等整页示意图 | 对应小节（flex 双图并排） |

**原书的图不是独立文件**：排版软件把插图导出成几百张碎片位图互相叠放，`extract_image` 只能拿到碎片。唯一可靠方法是**按坐标区域整页高分渲染再裁**（zoom 3–8 ＋差异蒙版自动裁边）。坐标三锚、边界三坑、QC 拼图流程见 `references/中译排版PDF.md` §4；样板 `assets/clip_railways_art.py`、`assets/clip_1880china_art.py`。

**图内英文标签保留不动**；图框里的规则文字另在 md 誊录为中文表，保证 md 单独可读。

### 2.4 完整性核查（构建脚本自带，必看两条）

1. **全部一二级标题出现在 PDF 文本层**——缺一个都要查原因；
2. **字符保真比** = PDF 提取字符数 ÷ md 去标记字符数，应 ≈ 1.0x（多出的是页脚/封面元信息；**明显 <1.0 说明丢内容**）。

**插图核验清单**：原书页 → 元素名 → md 锚点 → 排版版页 → 正文页，逐条 ✔；有任一项未核验不得交付。

## 4. 交付与发布（GitHub）

**独立仓库 `18xx-translation`，不复用 `WITE2_CN`**。仓库结构：

`@
README.md                 版本、目录、两部样板、版权与致谢
CHANGELOG.md              按版本倒序
skills/18xx-translation/  SKILL.md + references/ + assets/
works/Railways/           md + 排版版 PDF + 单人模式 + 疑惑与答疑
works/1880China/          md + 排版版 PDF + 疑惑与答疑
works/glossary/           18XX 中英术语对照表、规则总览
`@

发布纪律：

- **只发最新版**：同一作品有多个版本时，仓库只留最新一版；旧版在本地归档，不发布。
- **版本四处一致**：md 版本沿革、PDF 封面/页脚、git tag `vX.Y`、Release 标题。
- **不发英文原书 PDF、扫描件、游戏素材**；只发自己的译文、排版件、术语表。
- 版权声明：原文版权归原作者/出版社；译文与排版为 Pig9013 的劳动成果，仅供学习交流，禁止商用；权利人可联系删除。
- `.gitattributes` 写 `* -text`（防 Git 换行转换改字节；WITE2_CN 曾因 LF 转换导致整批校验失败）。
- 单文件 <100 MB；PDF 可直接入库（本项目单件 ≤25 MB）。

**Release 说明四段**：① 这版译了什么/排了什么；② 与上一版的差异（勘误、补页、插图）；③ 怎么核对（页数、标题数、字符保真比、插图 N/N）；④ 版权与致谢。

## 6. 已知坑（都踩过）

| 坑 | 现象 | 对策 |
|:--|:--|:--|
| 双栏用 `pdftotext -layout` | 左右栏串行，读起来是乱的 | PyMuPDF blocks 分栏 |
| 目录页码不更新 | 第一次打印就交付 | 两遍编译：扫描标题页→回填→重打 |
| 表格尾部单独一页无表头 | Edge 跨页不重复表头 | `thead{display:table-header-group}`；长表前强制分页 |
| 图压正文 | 浮动图太宽/太高 | 统一图宽；图后留 4mm；通栏图单独成块 |
| 插图混入邻栏文字/页码 | 裁剪框过大 | 先 `search_for` 量邻栏边界与原书页码，内收 4–8pt |
| 页脚 © 变 □ | 用了 simhei | 盖章一律 NotoSansSC/NotoSerifSC |
| PDF 标题是 xxx.html | Edge 默认元数据 | 后处理 `set_metadata()` |
| 改 PDF 不重生成 | 下次构建被覆盖、版本对不上 | 只改 `build_*_pdf.py` / `clip_*_art.py`，重新生成并升版本 |
| 整份重写 md | 输出昂贵且改坏无法回退 | 用 Edit 局部改；每 1–2 个窗口落整份快照 |
